# Resource coverage

These counts describe the resource index, not model quality or reproducibility. A **checked release entry** means that an official code, project, ecosystem, workshop, or challenge resource was verified.

The Phase-1 source audit was locked on **2026-09-07**. An additional targeted resource pass on **2026-09-18** resolved 11 papers that had previously been left as `Not indexed`. The dated additions are kept in [`resource_audit/resource_updates_2026-09-18.csv`](../resource_audit/resource_updates_2026-09-18.csv).
