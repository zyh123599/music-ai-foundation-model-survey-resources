# Datasets

Frequently used datasets mentioned in the survey. Access terms remain those of the original dataset owners.

| Dataset | Modality | Typical use | Scale | Access |
|---|---|---|---|---|
| [Million Song Dataset](https://millionsongdataset.com/) | audio features + metadata | MIR / large-scale retrieval | 1,000,000 tracks (features/metadata; no raw audio) | open metadata/features; audio not bundled |
| [AudioSet](https://research.google.com/audioset/) | general audio / music events | pretraining / event recognition | 2,084,320 human-labeled 10-second clips | YouTube-derived clips; ontology/labels public |
| [FMA](https://github.com/mdeff/fma) | music audio + metadata | genre / MIR / representation | 106,574 tracks | Creative Commons audio; code/data public |
| [MTG-Jamendo](https://mtg.github.io/mtg-jamendo-dataset/) | music audio + tags | music tagging / representation | 55k+ full tracks, 195 tags | research/non-commercial conditions; metadata/code public |
| [Lakh MIDI Dataset](https://colinraffel.com/projects/lmd/) | symbolic MIDI | symbolic modeling / generation | 176k+ unique MIDI files | symbolic data; matching code available |
| [MAESTRO](https://magenta.tensorflow.org/datasets/maestro) | aligned piano audio + MIDI | transcription / generation / performance | ~200 h aligned audio and MIDI | CC BY-NC-SA 4.0; versioned downloads |
| [MUSDB18](https://sigsep.github.io/datasets/musdb.html) | mixtures + stems | source separation | 150 full tracks (~10 h) | academic-use access; stems included |
| [MusicCaps](https://www.kaggle.com/datasets/googleai/musiccaps) | music audio + text captions | text-music generation / retrieval | 5.5k expert-written captions | YouTube-linked audio; captions public |
| [MusicBench (Mustango)](https://github.com/AMAAI-Lab/mustango) | music fragments + rich music-specific captions | controllable text-to-music | 52k music fragments | dataset/model links in official repository |
| [CMI-Bench](https://github.com/nicolaus625/CMI-bench) | music instruction benchmark | music instruction following | 14 MIR instruction tasks from 20 source datasets | benchmark assembly public; source licenses vary |
