# Models, code, and project resources

The machine-readable records are under [`resources/models/`](../resources/models/). This page is a shorter reading list. It separates released implementations from project pages when the distinction matters.

## Generation

- [YuE](https://github.com/multimodal-art-projection/YuE) — long-form music generation
- [Live Music Models](https://github.com/magenta/magenta-realtime) — real-time music generation
- [PADS-TAL](https://github.com/PADS-TAL/PADS-TAL) — text-to-music sampling
- [FusionAudio](https://github.com/FreedomIntelligence/FusionAudio) — fine-grained audio captioning with model/data release
- [SwanSphere](https://github.com/MM-Speech/SwanSphere) — streaming synchronized spatial audio generation; code released, checkpoint/data release still pending at the check date

The earlier Tencent GitHub URLs indexed for SongBloom and LeVo stopped resolving during the later link check. They remain in the historical audit rather than being replaced with an unverified mirror.
