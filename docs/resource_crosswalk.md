# Paper-resource crosswalk

The file [`resources/paper_resource_crosswalk.csv`](../resources/paper_resource_crosswalk.csv) joins the 120-paper review corpus with the resource audit.

For each paper it records, where available:

- paper and venue;
- official code/project/resource link;
- code-release status;
- checkpoint/weight notes;
- data-access notes;
- dataset or benchmark named in the resource audit;
- whether the paper has a benchmark entry in this repository;
- the GitHub revision checked on 2026-09-17.

The longer notes remain in the area-specific files under [`resources/models/`](../resources/models/). A blank cell means that the field has not been indexed here; it should not be read as evidence that a resource does not exist.
