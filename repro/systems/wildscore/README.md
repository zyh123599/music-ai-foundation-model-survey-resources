## Documented setup
`cd musictheory/final_code` and `pip install -r requirements.txt`.

## Minimal entry point
Run one of the model-specific evaluators: `python gpt.py`, `python phi.py`, `python qwen.py`, `python internvlm.py`, `python llava.py`, or `python miniCPM.py`.

## Evaluation
The evaluator scripts report overall and category-level accuracy. Some paths require API or Hugging Face credentials.
