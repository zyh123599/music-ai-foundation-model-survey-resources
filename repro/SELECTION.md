# Representative systems

The smoke-test subset is not a leaderboard. It was chosen to cover different parts of the survey while keeping the first reproducibility pass small enough to maintain.

The current set includes long-form generation, text-guided editing, multimodal generation, music-language benchmarks, representation learning, source separation/restoration, post-production, and evaluation.

A system enters this subset only when an official repository was located in the source audit. The subset can grow, but new entries should keep code availability, checkpoint availability, data availability, and runtime status as separate fields.
