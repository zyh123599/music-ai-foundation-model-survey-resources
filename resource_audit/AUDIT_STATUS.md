# Resource audit status

The 120-row survey corpus has no unindexed resource rows as of **2026-09-18**.

- 93 rows have a checked public resource entry.
- 26 rows have a dated targeted search in which no official code release was located.
- 1 row is held as a duplicate-title candidate pending manual corpus review.

- 71 concrete Git revisions are recorded in `checked_revisions.csv`; two older repository URLs are retained as unresolved historical links.

“Checked resource” is deliberately broader than “open-source code.” It can mean an official code repository, model release, dataset, benchmark/challenge resource, or project/demo page. The resource type and code status are separate columns in `resources/paper_resource_crosswalk.csv`.

No runtime or reproduction claim is made by this resource audit.
