# Technical crosswalk

These files keep the technical fields recorded during the source audit, split by year:

- `paper_technical_crosswalk_2024.csv` — 10 works
- `paper_technical_crosswalk_2025.csv` — 58 works
- `paper_technical_crosswalk_2026.csv` — 51 works

Together they contain **119 unique works**.

The columns cover task, input, output, model architecture, parameter count, dataset, benchmark status, official code/project link, checkpoint notes, data-access notes, and the GitHub revision checked when applicable.

The wording comes from the source audit. Missing architecture or release information is left unresolved instead of being inferred from a title.

The initial Phase-1 database had one duplicate SyMuPe title row; its removal is documented under `resource_audit/corpus_corrections.csv`.
