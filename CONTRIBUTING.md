# Contributing

Corrections and missing official links are welcome.

For a resource update, please include:

1. paper title and paper/venue URL;
2. author or organization code/project URL;
3. whether pretrained weights are available;
4. dataset or benchmark access information, when relevant;
5. the date the link was checked.

Use original project pages and author/organization repositories when possible. Please do not upload third-party model weights or datasets to this repository.
